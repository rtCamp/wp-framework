# wp-framework documentation configuration

This `docs-config` branch contains the Docusaurus builder, theme, sidebar, tests,
and dependency lockfile. Markdown and PHP source stay on `main`. Generated assets
are built for GitHub Pages artifacts and are never committed to either branch.
This branch has no dependency on `wp-tooling`.

## Local development

Requires Node.js 22+. Create a separate checkout beside the source repository:

```sh
git clone --single-branch --branch docs-config https://github.com/rtCamp/wp-framework.git wp-framework-docs-config
cd wp-framework-docs-config
npm ci
npm test
export DOCS_SOURCE="/absolute/path/to/wp-framework"
npm start -- --host 127.0.0.1 --no-open
```

Open http://127.0.0.1:3000/wp-framework/. Edit Markdown in the source checkout;
Docusaurus watches those files directly. For production validation:

```sh
npm run build
npm run serve -- --host 127.0.0.1 --no-open
```

If you already have the repository, a Git worktree avoids another clone. From the
source checkout, run `git worktree add ../wp-framework-docs-config docs-config`
after fetching the branch. Do not copy the builder into the source branch.

## Settings

| Environment variable | Default | Purpose |
| --- | --- | --- |
| `DOCS_SOURCE` | Required | Path to the separate source checkout |
| `DOCS_DIRECTORY` | `docs` | Markdown directory relative to that checkout |
| `DOCS_SOURCE_REF` | `main` | Branch/tag/commit used in GitHub source/edit links |
| `GITHUB_REPOSITORY` | `rtCamp/wp-framework` | GitHub repository identity |
| `PAGES_BASE_URL` | Derived GitHub Pages URL | Published site URL, including its path |

For local builds matching the currently configured Pages domain:

```sh
PAGES_BASE_URL=http://opensource.rtcamp.com/wp-framework/ npm run build
```

CI reads this value from `actions/configure-pages`, so domain changes do not
require edits here. Source links outside the Markdown directory become GitHub
links during rendering. Missing source files and broken documentation links or
anchors fail the build. The sidebar is autogenerated; Markdown front matter
controls page order and labels. Standard `.md` and opt-in `.mdx` are supported.

## Branch validation and later integration

`.github/workflows/docs-config.yml` runs on config-branch pushes and pull requests.
It checks out the config revision under test into `site/`, checks out `main` into
`source/`, installs the locked dependencies, runs tests, and builds the real docs.
It uploads `docs-config-preview` for inspection. **This setup-stage workflow does
not deploy the public site.**

The later `main` workflow will check out documentation and this branch separately,
then build and deploy a Pages artifact. It will replace the pending `website/`
implementation; that directory does not need committing to `main`. Automatic
production deployment after config changes can be enabled during that integration.
The old generated `documentation` branch is not used for Pages artifact deployment.

## Dependency maintenance

Docusaurus 3.10.2 and React 19.0.0 are pinned, including transitive dependencies via
`package-lock.json`. The current dependency tree has known npm audit advisories
(including image-size, serialize-javascript, qs, and uuid); the earlier compatible
audit fix did not resolve them. Review upstream updates before changing the lock.
